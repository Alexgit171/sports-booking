# Как проверить практическую работу № 2

## 1. Открыть правильную папку

В VS Code выберите **Файл → Открыть папку** и укажите папку
`sports-booking`. В проводнике VS Code на верхнем уровне должны быть видны
`main.py`, `grounds.py`, `bookings.py`, `storage.py`, `utils.py` и
`requirements.txt`.

Если терминал уже открыт в родительской папке `PR1_Ladinskiy`, выполните:

```powershell
cd sports-booking
```

Проверка текущей папки:

```powershell
dir
```

## 2. Подготовить окружение

Для Windows в терминале VS Code:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Активация окружения не обязательна: далее интерпретатор указан полным путём.

## 3. Запустить программу

```powershell
.\.venv\Scripts\python.exe main.py
```

Появится меню ПР2. Для быстрой проверки выберите `1`, затем `5`. Введите:

- имя: `Александр`;
- площадка: `1`;
- дата: `2026-10-01`;
- начало: `16`;
- длительность: `2`.

Бронь 16:00–18:00 должна создаться. Интервал 17:00–19:00 должен быть отклонён,
потому что пересекается с учебной бронью 18:00–20:00.

## 4. Запустить автоматические проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m flake8 .
.\.venv\Scripts\python.exe -m unittest -v
```

Ожидается 32 успешно пройденных теста ПР2, пустой вывод `flake8` и 13 успешно
пройденных тестов совместимости ПР1.

## 5. Запустить отладчик VS Code

1. Откройте `main.py`.
2. Поставьте точку останова слева от строки внутри `run_application()` либо
   внутри `create_booking()` в `bookings.py`.
3. Нажмите `F5`.
4. Выберите конфигурацию **ПР2: сервис бронирования**.
5. Используйте `F10` для шага без входа в функцию, `F11` для входа и `F5` для
   продолжения.

## 6. Зафиксировать изменения в Git

```powershell
git status
git add .
git commit -m "Реализовать практическую работу 2"
git push origin main
```

История коммитов:

```powershell
git log --oneline --decorate -5
```
