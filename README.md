## Назначение

Консольное приложение помогает пользователю найти спортивную площадку,
проверить свободное время, оформить или отменить бронирование и посмотреть
статистику. ПР2 продолжает рабочий сценарий ПР1 и сохраняет его функции для
демонстрации развития проекта.

## Возможности ПР2

- хранение нескольких площадок и бронирований в списках словарей;
- добавление, поиск, фильтрация и сортировка площадок;
- генератор для отбора площадок по виду спорта и цене;
- проверка пересечений временных интервалов;
- создание, поиск и отмена бронирований;
- расчёт количества заявок, уникальных пользователей и выручки;
- сохранение данных в JSON с контекстными менеджерами;
- обработка ошибок ввода и ошибок файлов;
- учебная интроспекция с `type`, `dir` и `hasattr`;
- аннотации типов и docstring для функций;
- проверки `pytest`, `unittest` и `flake8`.

Классы предметной области намеренно не используются: по методическим указаниям
они вводятся в ПР3.

## Предметная область и правила

Главная демонстрационная площадка — «СпортПарк» для мини-футбола. Она работает
с 08:00 до 22:00 и стоит 1500 рублей в час. На дату 2026-10-01 уже занято
18:00–20:00. Интервалы считаются полуоткрытыми: бронь до 18:00 и бронь с
20:00 допустимы.

Данные представлены стандартными коллекциями Python. Одна площадка и одно
бронирование — словари, набор записей — список. Это соответствует ограничениям
ПР2 и позволяет перейти к классам в следующей работе.

## Быстрый запуск в VS Code на Windows

Откройте именно папку проекта, затем в терминале выполните:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если терминал находится в папке `PR1_Ladinskiy`, сначала перейдите в проект:

```powershell
cd sports-booking
```

Полная инструкция находится в [START_HERE_PR2.md](START_HERE_PR2.md).

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m flake8 .
.\.venv\Scripts\python.exe -m unittest -v
```

`pytest` проверяет функции ПР2, `flake8` — оформление кода, а `unittest` —
совместимость со сценарием ПР1.

## Отладка

Откройте `main.py` или `bookings.py`, поставьте точку останова кликом слева
от номера строки и нажмите `F5`. Выберите **ПР2: сервис бронирования**.
На остановке можно увидеть аргументы, локальные переменные и стек вызовов,
затем выполнить строку клавишей `F10` или войти в функцию клавишей `F11`.
